Would you like to know more about “Would you like to know more?”

WYLTKM makes QR codes that lead from a thing to more information about it: a machine in the workshop, a project on the shelf, a talk or an assembly at congress. Each code has a short text on top, an icon in the middle and the line “would you like to know more?” at the bottom, so it is recognised as such wherever it hangs. It was made for the maker space Attraktor e.V. in Hamburg.

Making a code

  • Enter the link (or any text) that the code should contain, and a short title for the top. The preview follows as you type.
  • Pick a design. Some designs, like 40c3, offer several colour schemes; they appear as swatches below the designs.
  • Search an icon by name or meaning (“cat”, “laser”, “github”). Icons come from Font Awesome, IBM Carbon, the 40c3 style guide and the Attraktor logos. You can also upload your own SVG; it is only used for this image and not stored.
  • Download it as SVG for print and the laser cutter, or as PNG for screens. “Copy link” gives a link to exactly these settings.

Options

  • Border: a QR code needs a calm area around it, four modules wide, to scan reliably. “Quiet zone” adds it to the image. Leave it out when the code will sit on a large plain area anyway.
  • Background: transparent leaves out the background colour, for stickers and engraving.
  • Side text: prints the content of the code as readable text along the right side, for people without a scanner. Long links wrap into several columns.
  • Width: the width of the whole image in pixels (at most {{ max_width }}). For SVG it only sets the default size; the image scales without loss.

Printing and laser cutting

The SVG consists of filled paths only: the code, the text (as outlines, no fonts needed) and the icon. It can be scaled to any size and loaded into laser cutter and plotter software as it is. A few icons use strokes or clip paths, which some laser software ignores; the page warns about those. Test a printed code with a phone before making many.

Licences

Each image is made of parts with their own licences: the design, the icon and the fonts. The page lists them under the preview, and by default the image file contains them as well. Some icons, like those from Font Awesome, require attribution. See all licences.
